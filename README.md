# speedgamer21.github.io

Personal portfolio of Aljann Avanzado, served with GitHub Pages.

- Plain HTML/CSS/JS, no build step: edit `index.html`, `assets/css/styles.css`, `assets/js/main.js`.
- Light/dark theme (follows the system, toggle is remembered).
- The Projects section is filled at runtime from the public GitHub repos of `SpeedGamer21`
  (forks and archived repos are skipped; change `GITHUB_USER` / `MAX_PROJECTS` in `main.js`).

Preview locally: `python3 -m http.server` and open http://localhost:8000.
